# TrueStats ДДС бот (@kirpix_dds_bot)

Сидит в Telegram-чате «Д_Д_С_Kirpix». Когда кидают скрин/PDF перевода с подписью
(«Фбс, Вешки, за 14 окт. Все магазины Вб. Модуль»), бот:

1. читает чек через Claude (сумма, дата, получатель, банк);
2. по подписи определяет статью и кабинеты (правила в `rules.py`, сняты с прошлых записей TrueStats);
3. отвечает карточкой с кнопками **✅ Внести / ⏭ Пропустить / ✏️ Как исправить**;
4. после ✅ создаёт операцию в TrueStats (Финансы → Операции) через внутренний API `api.truestats.ru`.

Сомы (Optima) сам не пересчитывает: просит ответить на карточку суммой в рублях.
Перед записью проверяет дубль (та же дата, сумма, назначение).

## Команды в чате
- `/ping` — жив ли бот, режим (тест/боевой), настроен ли TrueStats
- `/id` — chat_id и твой user_id
- `/сверка` — что внёс бот сегодня и что лежит в TrueStats за сегодня

## Правки карточки
Ответь на карточку текстом:
- `9500` — сумма в рублях (для сомов)
- `статья: Грузчики`
- `магазины: все магазины озон` или `магазины: Kirpix WB, Letics`
- `дата: 16.10.2026`
- `назначение: Жоомарт, аванс`

## Настройка (`.env`)
```
TELEGRAM_BOT_TOKEN=...          # от @BotFather (уже заполнено)
TELEGRAM_CHAT_ID=                # id группы (бот покажет по /id); через запятую можно несколько
APPROVER_USER_IDS=              # кто может жать ✅ (user_id через запятую). Пусто = любой в чате
DRY_RUN=1                       # 1 = карточки без записи в TrueStats, 0 = боевой
ANTHROPIC_API_KEY=              # ключ Claude API (console.anthropic.com). На сервере обязателен; пусто = запасной путь через локальный `claude -p`
CLAUDE_MODEL=claude-sonnet-5
TRUESTATS_EMAIL=                # логин TrueStats (лучше отдельный пользователь с правами на операции)
TRUESTATS_PASSWORD=
TRUESTATS_BILL=Основной счёт
```

## Запуск
Windows (пилот): `run.bat` или `python bot.py`. Лог: `data/bot.log`.

Mac mini (постоянно, одна команда в Терминале):
```bash
curl -fsSL https://raw.githubusercontent.com/aisezimm00/truestats-bot/main/install.sh | bash
```
Перед первым запуском положить файл настроек `truestats-bot.env` (это `.env` с заполненным
`ANTHROPIC_API_KEY`) в папку «Загрузки». Скрипт сам ставит uv + Python 3.13, библиотеки,
регистрирует автозапуск через launchd (`~/Library/LaunchAgents/com.kirpix.truestats-bot.plist`,
KeepAlive) и запрещает Mac засыпать (`pmset`). Повторный запуск той же команды = обновление кода.
Чтобы бот поднимался после перезагрузки без человека, включить автологин:
Системные настройки → Пользователи и группы → Автоматический вход.

Остановить: `launchctl bootout gui/$(id -u)/com.kirpix.truestats-bot`.
Логи: `~/truestats-bot/data/bot.log`. Проверка из чата: `/ping`.
Одновременно два экземпляра бота (ноут + Mac) запускать нельзя: Telegram отдаёт апдейты только одному.

## Как включить боевой режим
1. В `.env` заполнить `TRUESTATS_EMAIL/PASSWORD` (и `ANTHROPIC_API_KEY`, если есть).
2. `python test_truestats.py` — логинится, печатает список кабинетов/статей/счетов, создаёт и тут же удаляет
   тестовую операцию на 1 ₽ (проверка, что формат запроса принят).
3. Поставить `DRY_RUN=0`, перезапустить бота.

## Файлы
- `bot.py` — Telegram-логика, карточки, кнопки, правки, сверка, sqlite `data/state.db`
- `receipt_parser.py` — чтение чека (Claude API или `claude -p`), PDF→PNG
- `rules.py` — подпись → статья, кабинеты, назначение (**тут все соглашения**)
- `truestats_client.py` — вход, refresh, справочники, создание/список/удаление операций
- `test_rules.py`, `test_parse_export.py`, `test_truestats.py` — проверки

## Известные ограничения
- API TrueStats недокументированный, снят с фронтенда (сборка prod-270585b1-20261016). Обновят интерфейс — может сломаться.
  Запасной путь: Excel-импорт (кнопка «Импорт» в Операциях) или Playwright по форме.
- Бот видит только сообщения после добавления в чат (чеки до 17.10 не увидит).
- Один чек = одна операция. Если в одном сообщении несколько скринов, бот сделает карточку на каждый с общей подписью.


## Валюта (KGS, USD, EUR, KZT, CNY) → рубли
Чек в сомах бот сам пересчитывает в рубли по официальному курсу НБКР (`fx.py`, https://www.nbkr.kg/XML/daily.xml, кэш на сутки, запасной источник er-api.com).
В карточке строка «Исходно: 30 000 KGS, курс 1.0575 (НБКР …)». Если курс не устраивает, ответь на карточку числом: это сумма в рублях, она перебивает расчёт.
Зафиксировать свой курс: `KGS_PER_RUB=1.06` в `.env` (сомов за 1 рубль).

## Чек без подписи / «туда же»
Если чек пришёл без подписи или с подписью вида «туда же», «тоже», «+», «ещё», бот берёт подпись последнего чека в этом чате за 6 часов (пропущенные не считаются) и разбирает новый чек с ней: та же статья, те же магазины, то же назначение, сумма и дата со своего чека. В карточке строка «↩️ Подписи не было, взял от предыдущего чека: «…»». Если наследование не то, ответь на карточку правкой (`статья: …`, `магазины: …`, `назначение: …`). Окно задаётся константой INHERIT_HOURS в bot.py.

## Неизвестная статья → «Расходы»
Если в подписи нет ни одного ключевого слова из ARTICLE_RULES (rules.py), статья ставится «Расходы», назначение = подпись без хвоста про магазины и банк («Коробки для поставок Озон. Все магазины Озон. Модуль» → «Коробки для поставок Озон»). В карточке предупреждение «Статью по подписи не узнал, поставил «Расходы»», кнопка «Внести» доступна. Явные ключи для «Расходы»: коробки, упаковочные, скотч, пакеты, расходники, канцелярия, хозтовары. «Водителю»/«курьер» → Доставка / Перевозка.

## Бренд + площадка в свободной форме
«MakeEyes магазины все на вб», «Kirpix все магазины на вб», «Kirpix и Letics на вб», «мейкайс льготный вб» → кабинеты этого бренда на этой площадке (BRAND_WORDS / BRAND_STORES / stores_by_brand в rules.py). Бренд без площадки → все кабинеты бренда. «льготн» оставляет только льготные. Если в подписи есть бренд, «все магазины» относится к бренду, а не ко всем 12. Точные алиасы («Kirpix WB» = только основной кабинет) по-прежнему в приоритете.

## Любая трата = операция
Скрин не обязан быть чеком: строка из истории операций, списание за подписку (OpenAI и т.п.), оплата картой тоже идут в карточку, если видна сумма. «Вчера/Сегодня» модель переводит в дату сама без предупреждения. Валюта любая: USD/EUR/KZT/CNY считаются через курсы НБКР кроссом к рублю (`fx.rub_per_unit`), override `RUB_PER_USD=82.5` в .env.
